# ПР2. Детекція об'єктів

Завантажуєш фото, модель YOLOv8n знаходить на ньому об'єкти, сторінка малює рамки і таблицю з класами та впевненістю. Поріг впевненості можна міняти.

- `app/detector.py` - завантаження моделі, перевірка файлу, inference
- `app/main.py` - ендпоінт `POST /api/detect`
- `eval/run_eval.py` - прогін свого набору фото з порогами 0.25 і 0.5
- `eval/RESULTS.md` - що вийшло і висновки

Ваги `yolov8n.pt` скачуються самі при першому запуску. Фото для оцінювання в репозиторій не додавав.

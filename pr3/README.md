# ПР3. Помічник служби підтримки

Відповідає на питання клієнтів магазину тільки за правилами з `context.md`. Працює з Gemini через OpenAI-сумісний API.

Перед запуском скопіювати `.env.example` у `.env` і вписати свій ключ з Google AI Studio.

- `app/llm.py` - промпт, виклик моделі, повтори і помилки (ключ, ліміт, таймаут, сервіс недоступний)
- `app/main.py` - ендпоінт `POST /api/ask`
- `compare/run_compare.py` - один набір питань з температурою 0.2 і 1.2
- `compare/findings.md` - висновки

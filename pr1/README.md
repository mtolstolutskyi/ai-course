# ПР1. Погода

Вводиш місто, застосунок знаходить його координати через geocoding API Open-Meteo і показує поточну погоду.

- `app/weather.py` - запити до Open-Meteo, обробка помилок (місто не знайдено, сервіс недоступний, таймаут)
- `app/main.py` - ендпоінт `GET /api/weather?city=...`
- `screenshots/` - як це виглядає

Ключ не потрібен.
